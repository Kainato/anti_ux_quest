Politica de Privacidade - Anti-UX Quest

Ultima atualizacao: 27 de novembro de 2026

Esta Politica de Privacidade descreve como o app Anti-UX Quest trata dados de usuario e do dispositivo.

1. Dados coletados

O Anti-UX Quest nao coleta, nao armazena em servidor e nao vende dados pessoais identificaveis de usuarios.

O app pode salvar localmente no proprio dispositivo apenas preferencias e progresso de jogo (por exemplo: tema e fases concluidas) para manter a experiencia entre sessoes.

2. Como os dados sao usados

  • Manter o funcionamento do jogo e do progresso local.
  • Aplicar preferencias de interface (como tema claro/escuro).

Esses dados sao utilizados somente para o funcionamento do app no dispositivo e nao sao usados para publicidade comportamental.

3. Compartilhamento de dados

O Anti-UX Quest nao compartilha dados pessoais do usuario com terceiros.

4. Seguranca

Como os dados ficam no proprio dispositivo, o usuario pode removelos ao desinstalar o app ou limpar seus dados nas configuracoes do sistema.

5. Publico infantil

Este app nao foi projetado especificamente para criancas. Mesmo assim, a politica de dados acima se aplica a todos os usuarios.

6. Alteracoes nesta politica

Esta politica pode ser atualizada para refletir novas funcionalidades do app ou exigencias legais. A versao publicada nesta URL e a mais atual.

7. Contato

Para duvidas sobre esta Politica de Privacidade, abra uma issue no repositorio do projeto em https://github.com/Kainato/anti_ux_quest.
